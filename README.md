# Libft - Custom C Library

Libft is a custom C library built as part of the curriculum at [42 School](https://www.42.fr/). It reimplements several standard C library functions and introduces additional utility functions to assist in C programming.

## Table of Contents

- [Overview](#overview)
- [Features](#features)
- [Building the Library](#building-the-library)
---

## Overview

The goal of this project is to create a personalized version of the standard C library, allowing us to deepen our understanding of C programming and gain insights into how standard library functions work under the hood.

## Features

- Reimplementation of standard library functions such as `strlen`, `strcpy`, `strdup`, etc.
- Memory manipulation functions like `memset`, `memcpy`, and `calloc`.
- String manipulation utilities.
- List management functions for handling linked lists.
- Additional utility functions for common programming tasks.
